# core-linear-regression

Практический проект по реализации базовых алгоритмов машинного обучения и методов оптимизации с нуля на чистом Python (NumPy/Pandas) для глубокого изучения их математической основы.

## 🛠 Основной функционал

*   **Модели:** Linear Regression (МНК и градиентный спуск), Ridge (L₂-регуляризация), Lasso (L₁-регуляризация) и ElasticNet (гибридная регуляризация) с интерфейсом `.fit()` и `.predict()`.
*   **Оптимизация:** Аналитическое решение, классический градиентный спуск (GD) и стохастический градиентный спуск (SGD).
*   **Предобработка:** Кастомные скейлеры `MinMaxScaler` и `StandardScaler`.

## 📊 Исследовательская часть и пайплайн

Проект протестирован на датасете с Kaggle и включает Feature Engineering (генерацию признаков из текста), бенчмаркинг со `sklearn` (метрики MAE, RMSE, R² идентичны), стресс-тестирование на переобучение полиномиальными признаками и подбор коэффициента регуляризации α.

## 🗂 Структура и стек

*   `src/` — исходный код моделей и скейлеров.
*   `notebooks/` — Jupyter Notebook с полным пайплайном и визуализацией.
*   **Стек:** Python 3.x, NumPy, Pandas, Matplotlib, Seaborn, Collections.
